# SAT CSS Framework
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

A modern, lightweight, and self-contained CSS framework built for production.

SAT CSS provides utility-first classes, layout systems, component foundations, and full RTL (Right-To-Left) support, making it an excellent choice for modern web development.

## Features
- **Zero Dependencies:** Pure CSS, no Javascript dependencies needed.
- **Lightweight:** Around 20-30 KB (minified and compressed).
- **RTL Support:** Full support for RTL languages like Arabic, Urdu, and Persian out of the box.
- **Utility-First:** Over 800-1000 practical utility classes.
- **Production Ready:** Minified and concatenated for immediate use.

## Quick Start

### Direct Download
Download the `dist/sat-css.min.css` file and include it in your HTML:

```html
<link rel="stylesheet" href="path/to/sat-css.min.css">
```

### Installation via NPM
```bash
npm install @shoaib-aftab-tech/css
```

Then import it in your project:
```javascript
import '@shoaib-aftab-tech/css/dist/sat-css.min.css';
```
