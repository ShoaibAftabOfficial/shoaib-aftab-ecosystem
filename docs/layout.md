# Layout

Control display, flexbox, and grid setups easily.

## Flexbox

```html
<div class="sat-flex sat-justify-between sat-items-center sat-bg-gray-100 sat-p-4">
  <div>Left Item</div>
  <div>Right Item</div>
</div>
```

## Grid

```html
<div class="sat-grid sat-grid-cols-3 sat-gap-4">
  <div class="sat-bg-primary-200 sat-p-4">Col 1</div>
  <div class="sat-bg-primary-200 sat-p-4">Col 2</div>
  <div class="sat-bg-primary-200 sat-p-4">Col 3</div>
</div>
```
