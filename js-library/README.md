# SAT JS Library
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

A modern, lightweight, and self-contained JavaScript utility and DOM manipulation framework.

## Features
- **Lightweight:** Tiny footprint without heavy dependencies.
- **Utility Functions:** Easy to use functions for common operations.
- **DOM Manipulation:** Streamlined API for element interactions.
- **Production Ready:** Minified and bundled versions included.

## Quick Start

### Installation via NPM
```bash
npm install @shoaib-aftab-tech/js
```

Then import it in your project:
```javascript
import { $ } from '@shoaib-aftab-tech/js';
```

### Direct Download
Download the `dist/sat-js.min.js` file and include it in your HTML:
```html
<script src="path/to/sat-js.min.js"></script>
```
