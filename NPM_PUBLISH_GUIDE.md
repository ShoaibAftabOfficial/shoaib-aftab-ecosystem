# Shoaib Aftab NPM Publishing Guide

This guide provides step-by-step instructions on how to publish the **Shoaib Aftab CSS** and **Shoaib Aftab JS** libraries to your personal NPM account (`@shoaib-aftab`).

## 1. Prerequisites
Ensure you have Node.js and NPM installed on your local machine. You must also have your NPM account credentials ready.

## 2. Login to NPM
Open your terminal and run the following command to log into your NPM account:
```bash
npm login
```
*You will be prompted to enter your username (`shoaib-aftab`), password, and email address.*

## 3. Publishing the CSS Framework
1. Navigate to the root folder of the repository (where the main `package.json` for CSS is located).
2. Ensure the latest build has been generated by running:
   ```bash
   npm run build
   ```
3. Publish the package. Because this package uses a scoped name (`@shoaib-aftab/css`), NPM treats it as private by default. Since you likely do not have a paid NPM account for private scoped packages, you **must** pass the `--access public` flag:
   ```bash
   npm publish --access public
   ```

## 4. Publishing the JS Library
1. Navigate into the JavaScript library directory:
   ```bash
   cd js-library
   ```
2. Ensure the latest JS build has been generated by running:
   ```bash
   npm run build
   ```
3. Publish the package with public access:
   ```bash
   npm publish --access public
   ```

## 5. Verifying the Publish
Once published, you can visit your NPM profile to verify that the packages are live:
- [https://www.npmjs.com/package/@shoaib-aftab/css](https://www.npmjs.com/package/@shoaib-aftab/css)
- [https://www.npmjs.com/package/@shoaib-aftab/js](https://www.npmjs.com/package/@shoaib-aftab/js)

## Notes on Future Updates
Whenever you make changes to the CSS or JS libraries:
1. Increase the `"version"` number in the respective `package.json` file (e.g., from `1.0.0` to `1.0.1`).
2. Run `npm run build`.
3. Run `npm publish --access public` again.
