# Shoaib Aftab Tech - Website Source Code

This directory contains the modernized, Progressive Web App (PWA) version of the Shoaib Aftab Tech website, built purely with **Vite**, **Shoaib Aftab CSS**, and **Shoaib Aftab JS**.

## Features

- **PWA Ready:** Users can install the website as an app on their mobile or desktop devices.
- **Shoaib Aftab CSS Powered:** Utilizes the custom lightweight utility CSS framework for all styling.
- **Shoaib Aftab JS Powered:** Utilizes the custom JS library for interactions (Mobile Menu, Live Demo Login).
- **Responsive:** Fully responsive on all devices.
- **Infinite Marquee:** CSS-only animation for the client logo showcase.

## How to Run Locally

1. `npm install`
2. `npm run dev` to start the local Vite dev server.
3. `npm run build` to compile the production ready files into the `dist` folder.
